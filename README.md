# loore-docs

Публичная документация Loore — источника данных Instagram для AI-агентов. Публикуется на **https://docs.loore.ai** (Mintlify, синхронизация из этого репозитория).

## Принцип: ничего, что может разойтись, не пишется руками

Loore публикует один OpenAPI-документ, который сервер собирает из **того же реестра**, что определяет инструменты MCP: `operationId` — это одновременно имя MCP-инструмента и REST-операция. Поэтому весь справочник генерируется из него:

| Файл | Кто пишет |
| --- | --- |
| `openapi.json` | генератор (копия живого контракта) |
| `mcp/tools.mdx` | генератор (таблица всех инструментов) |
| остальные `.mdx` | люди — объяснения, рецепты подключения, правила |

```bash
node scripts/generate.mjs          # обновить сгенерированное
node scripts/generate.mjs --check  # упасть, если разошлось (локальный гейт)
LOORE_OPENAPI_URL=… node scripts/generate.mjs   # другая среда
```

`scripts/check.sh` запускает `--check` перед каждым пушем: документация, разошедшаяся с продом, не мержится. Отдельный воркфлоу раз в сутки регенерирует и открывает коммит, если контракт изменился.

## Проверки перед пушем

GitHub Actions CI для проверок не используется (решение владельца, 2026-10-12). Перед каждым пушем локально идёт `scripts/check.sh` (сверка сгенерированных страниц с живым контрактом, нужна сеть). Один раз на клон:

```bash
git config core.hooksPath .githooks
```

Хук `.githooks/pre-push` блокирует пуш при ошибке.

## Структура

```
docs.json            конфигурация Mintlify (навигация, тема, домен)
index.mdx            что такое Loore
quickstart.mdx       путь от ключа до первого ответа
authentication.mdx   ключ, заголовок, отказы
clients/             рецепты подключения (терминал и приложения)
mcp/tools.mdx        ГЕНЕРИРУЕТСЯ: все инструменты
concepts/            скиллы, ошибки, тарификация
openapi.json         ГЕНЕРИРУЕТСЯ: машинный контракт
AGENTS.md            короткая страница для самого агента
```


## Правила

- Не публиковать ключи, внутренние адреса и незапущенные обещания. Если функции ещё нет — так и пишем.
- Цены не дублируем: они живут на loore.ai, документация обновляется реже витрины.
- Правки в сгенерированные файлы бессмысленны — их перезапишет следующий прогон.
