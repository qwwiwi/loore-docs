## Конверт

Успех и отказ приходят в одной форме — агенту не нужно угадывать:

```json
{ "status": "ok", "result": { } }
```

```json
{ "status": "error", "error": "unauthorized", "details": { } }
```

`result` есть только при `status: "ok"`. `details` присутствует не всегда — это машинные подробности отказа, а не текст для человека.

## Коды

| Код | Когда | Что делать агенту |
| --- | --- | --- |
| `200` | успех | читать `result` |
| `400` | тело запроса или аргументы не проходят валидацию | исправить аргументы, не повторять вслепую |
| `401` | ключа нет, он испорчен или отозван | проверить заголовок `Authorization`; повтор не поможет |
| `402` | закончились кредиты или квота тарифа | остановиться и сообщить пользователю |
| `403` | ключ не имеет прав на этот метод | метод вне области ключа; другой метод может работать |
| `404` | объект владельца не найден | проверить идентификатор; чужой объект тоже отвечает `404` |
| `409` | конфликт устойчивого состояния: ключ идемпотентности переиспользован с другим телом, задача уже в работе, соединение не принимает запись | не «чинить» повтором с тем же ключом |
| `429` | исчерпан бюджет запросов тарифа | повторить позже с задержкой |
| `500` | непредвиденная ошибка сервера | можно повторить один раз |
| `502` | метод объявлен, но реализации за ним ещё нет | не повторять |

<Note>
  Чужой объект отвечает ровно тем же `404`, что и несуществующий — по коду ответа нельзя проверить, существует ли чужая запись.
</Note>

## Идемпотентность

Методы, которые тратят деньги или создают долгоживущие объекты, принимают заголовок `Idempotency-Key`. Повтор с **тем же** ключом и **тем же** телом безопасен — вернётся первый результат. Повтор с тем же ключом и другим телом даёт `409`: это защита от того, чтобы одна операция не превратилась в две.
