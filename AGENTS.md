# Loore для агента

Ты агент. Это страница для тебя, не для человека — она короткая нарочно.

## Что такое Loore

Источник данных Instagram: метрики аккаунтов и рилсов, транскрипты и кадры, конкуренты в нише, музыкальные тренды, скачивание медиа файлом. Loore возвращает **факты**, разбор пишешь ты.

## Как подключиться

Один ключ, две двери. Ключ владелец берёт в кабинете `https://app.loore.ai` → Настройки → API и MCP.

1. **MCP** — `https://mcp.loore.ai/mcp`, заголовок `Authorization: Bearer <ключ>`.
2. **REST** — `POST https://mcp.loore.ai/v1/<метод>`, тот же заголовок, тело JSON.

Имя инструмента в MCP и путь REST — одна операция: `ig_analytics` ↔ `POST /v1/ig-analytics`.

Машинный контракт: `https://app.loore.ai/api/openapi.json` (тот же файл лежит в этом репозитории как `openapi.json`).

## Формат ответа

```json
{ "status": "ok", "result": { } }
{ "status": "error", "error": "...", "details": { } }
```

Коды: `400` неверные аргументы, `401` ключ, `402` кончились кредиты/квота, `403` метод вне прав ключа, `404` объект не найден (чужой отвечает так же), `409` конфликт идемпотентности или задача уже в работе, `429` бюджет запросов исчерпан, `500` ошибка сервера, `502` метод без реализации.

На `401`, `403`, `402`, `502` повтор бессмысленен — остановись и скажи человеку. На `429` — подожди.

## Скиллы

`skill_list` показывает готовые пайплайны, `skill_run` запускает (асинхронно, вернёт `runId`), `skill_run_status` опрашивает результат. Они выполняются **на стороне Loore** — устанавливать себе нечего.

## Правила хорошего тона

- Ключ не печатай в чат и не клади в файлы репозитория.
- Тяжёлые методы (глубокий разбор рилса, скачивание медиа) стоят дороже — не гоняй их в цикле «на всякий случай».
- Идемпотентность: у денежных и долгих операций передавай `Idempotency-Key`; повтор с тем же ключом и телом безопасен.
